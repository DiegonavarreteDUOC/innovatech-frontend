# React + Vite
Esta plantilla ofrece una configuración básica para que React funcione en Vite con HMR y algunas reglas de ESLint.

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react/README.md) usa [Babel](https://babeljs.io/) para una actualizacion rapida
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react-swc) usa [SWC](https://swc.rs/) para una actualizacion rapida
